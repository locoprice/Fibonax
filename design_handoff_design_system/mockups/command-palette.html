Try it

  • Click the search bar, or press Ctrl K (⌘ K on a Mac). The search window opens.
  • Empty box: what you opened lately, by day.
  • Type resume to find "Résumé", or cafe to find "café" inside a Brain item.
  • Type refund: names first, then texts that mention it, with the sentence shown.
  • ↑ ↓ and the mouse move the same highlight. ↵ opens. Ctrl ↵ opens in a new tab.
  • Esc clears the text first, then closes.
  • Chips: Title only, Created by, In, and + Filter for type, labels and date edited.
  • The sparkle button switches to asking FiboChat (dashboard and phone).
  • In the popup, just start typing: the window opens with your letters in it.

Thin grey rows while the very first copy of your library arrives. After that it opens at once, even offline.

What stays the same

  • Every search bar stays where it is today and looks the same.
  • No new colours. The window uses the colours Fibonax already has, in light and dark.
  • Only the behaviour changes: clicking the bar opens the search window.
